# كاشف اللعبة النشطة على PS5 — v0.1

هذه أول وحدة فعلية من مشروع المترجم العربي. وظيفتها حالياً اكتشاف حالة اللعبة فقط، وليست مترجماً بعد.

## شنو تسوي النسخة؟

- تتصل محلياً من داخل PS5 إلى ShadowMountPlus على `127.0.0.1:10101`.
- تقرأ `/api/v1/kernel-log` دون إرسال طلبات إلى الحاسبة أو الإنترنت.
- تستخرج `Title ID` وPID وAppID من أحداث OnionHEN عند توفرها.
- تقارن `VideoOut` مع `SetControllerFocus` حتى تميز اللعبة النشطة عن واجهة PS5.
- تعرض معلومات التشخيص داخل صفحة ProsperoMenu وتحدّثها كل ثانيتين أثناء فتح الصفحة.
- لا تغيّر Mount ولا ملفات الألعاب ولا إعدادات ShadowMount.

## حالة التحقق

**تم اختبار منطق التحليل محلياً على الحاسبة باستخدام أمثلة سجلات الاختبار التي أرسلها المستخدم.** اختبارات C تشمل: اللعبة في الواجهة الأمامية، اللعبة بالخلفية مع تركيز Shell، إغلاق اللعبة، فك JSON مع النصوص المهروبة، ومطابقة اسم اللعبة من قائمة ShadowMountPlus. كما اجتاز عميل HTTP اختبار اتصال مع خادم محلي تجريبي يحاكي مسار `kernel-log`.

**لم يتم بناء ملف PS5 `.ovl` بعد، ولم يتم اختباره على جهاز PS5.** بيئة البناء المتاحة هنا لا تحتوي على Zig ولا PS5 Payload SDK. لذلك لا تنسخ أي ملف ELF/OVL للجهاز من هذه الحزمة؛ لا يوجد ملف ثنائي جاهز ضمنها.

## متطلبات البناء

- نسخة مصدر ProsperoMenu المطابقة للنسخة المثبتة على جهازك، وتتضمن `sdk/include/pmo.h` و`sdk/src/pmo.c`.
- PS5 Payload SDK v0.43.
- Zig 0.14.1.
- Node.js 24+ بحسب متطلبات مستودع ProsperoMenu الحالي.

## طريقة البناء على Windows داخل مجلد ProsperoMenu

1. فك ضغط هذا المشروع.
2. جهّز نسخة مصدر ProsperoMenu الكاملة، وأدوات Zig وPS5 Payload SDK المذكورة أعلاه، واضبط متغيرات البيئة `ZIG` و`PS5_PAYLOAD_SDK` حسب مساراتها عندك.
3. افتح PowerShell داخل مجلد المشروع الذي فكّيت ضغطه.
4. شغّل السكربت مع مسار مجلد ProsperoMenu عندك:

   ```powershell
   .\build-overlay.ps1 -ProsperoMenuRoot "D:\PS5\Prospero-Menu"
   ```

   استبدل المسار بمكان نسخة ProsperoMenu الفعلية عندك. السكربت ينسخ ملفات المصدر الستة إلى `sdk\examples\ps5-ar-detector` ثم يشغّل بناء الإضافة.
5. إذا اكتمل البناء، الناتج سيكون داخل:
   `build/overlays/ps5-ar-detector/`

   ويحتوي `overlay.json` و`ps5-ar-detector.ovl`.
6. انسخ مجلد الناتج `ps5-ar-detector` إلى:
   `/data/ProsperoMenu/overlays/`
7. من ProsperoSettings اختر Reload overlays، ثم افتح PS5 Game Detector.

لا تنفذ خطوات البناء إذا ما عندك نسخة المصدر وأدوات البناء المطلوبة. نجاح البناء على الحاسبة لا يثبت وحده التوافق على firmware 13.20؛ يلزم اختبار على الجهاز.

## اختبار منطق التحليل على الحاسبة

داخل مجلد المشروع:

```bash
make test
make check
```

`make test` يشغّل اختبارات التحليل، و`make check` يفحص بناء ملفات C نحوياً باستخدام تعريفات واجهة ProsperoMenu التجريبية المرفقة. أو يدوياً:

```bash
clang -std=c11 -Wall -Wextra -Werror -O2 -I. detector.c tests/test_detector.c -o test_detector
./test_detector
```

## طريقة الكشف وحدودها

أقوى حالة `Game active` تتطلب تطابق ثلاثة مؤشرات: PID اللعبة مع PID حدث VideoOut، وAppID اللعبة مع AppID حدث VideoOut، وAppID التركيز الحالي من `SetControllerFocus`.

حالة `Game in background / Shell` تعتمد على وجود حدث بدء لعبة معروف مع انتقال تركيز يد التحكم إلى AppID الخاص بالـShell/Home (0x8 أو 0x7)، أو انتقال مشهد ShellUI إلى مشهد النظام.

التحليل يستخدم tail سجل الأحداث؛ إذا كان السجل مقتطعاً أو فقد حدث بدء اللعبة، قد يعرض `State uncertain`. كما أن رسائل بدء اللعبة المعتمدة على OnionHEN قد لا تتوفر عند اختلاف payload أو صيغة السجل. لا يعتمد الكود على offsets للنواة، وهذا يقلل مخاطر اختلاف الفيرموير، لكنه لا يثبت وحده توافق Overlay SDK مع 13.20.

## ملاحظة عن الواجهة

ProsperoMenu يرسم صفحة الإضافة داخل قائمته فوق اللعبة عند فتح القائمة. هذه النسخة لوحة تشخيص تظهر داخل ProsperoMenu، وليست HUD ترجمة ثابتاً فوق اللعب. سنحتاج في مرحلة لاحقة مسار عرض مستقل للنصوص المترجمة.

## ملاحظة أمنية

الطلب يذهب إلى loopback فقط (`127.0.0.1`)، ولا يتصل بعنوان الحاسبة أو شبكة LAN. لا تفتح منفذ ShadowMount على الإنترنت؛ توثيق ShadowMount يذكر أن API لا يوفّر مصادقة.
